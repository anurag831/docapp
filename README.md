# DocApp — Google Docs Lite

## Local Setup

```bash
git clone <repo>
cd docapp
npm install
cd client && npm install && cd ..
npm run dev          # starts both server (3001) and client (5173)
```

Open http://localhost:5173. Log in as Alice, Bob, or Carol.

## Supported File Uploads
.txt and .md only. Files are converted to editable documents.
